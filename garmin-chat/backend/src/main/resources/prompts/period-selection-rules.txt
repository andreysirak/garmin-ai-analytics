Period rules (reference date is server context):
- LAST_N_DAYS: completed days ending yesterday, e.g. past seven days or past week. Send {"type":"LAST_N_DAYS","days":7}. For N weeks use 7*N days.
- LAST_WEEK: previous calendar Monday through Sunday. Send only {"type":"LAST_WEEK"}.
- THIS_WEEK, LAST_MONTH, THIS_MONTH, YESTERDAY, TODAY: send only the matching type. Java calculates dates.
- EXPLICIT: unambiguous dates stated by the user, with years. Send type, startDate and endDate as inclusive yyyy-MM-dd. Repeat the date for a single day.
- Never invent a period, copy the reference date as user input, or fill fields belonging to another period type. Missing or ambiguous periods require CLARIFY, unless the whole request is UNSUPPORTED.
